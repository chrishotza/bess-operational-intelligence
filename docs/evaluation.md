# Evaluation

## Public evaluation model

The public technical model follows:

```text
Operating Conditions
        ->
Operating Regime
        ->
Supervisory Decision
        ->
Constraint State
        ->
Decision Reason
```

## Representative scenarios

The public evaluation concept covers:

- Normal
- Peak
- Low SOC
- Outage
- Recovery
- Generation Loss

## Evaluation objective

A technical reviewer should be able to understand:

1. what operating context is being considered;
2. how the operating regime changes;
3. how the supervisory decision changes;
4. how reserve, service and safety considerations remain present;
5. how the resulting decision can be explained at a high level.

## Technical progression

The current technology is prepared for source-free Pre-HIL evaluation.

The evaluation path can be used to identify:

- adapter requirements
- signal requirements
- timing requirements
- model assumptions
- integration dependencies
- validation gaps

The subsequent step toward physical evidence is partner or
laboratory technical scoping followed by the required integration
and validation work.
